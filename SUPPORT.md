# Getting help

- **How to use MasterSafe:** the Help page inside the program, the [user documentation](docs/Documentation.md), and the
  [article about MasterSafe](https://www.gabriel-vergara.com/articles/mastersafe-authenticator/).
- **Where your files are:** [docs/FileLocations.md](docs/FileLocations.md).
- **Is my download genuine?** See [How to verify a download](README.md#how-to-verify-a-download).
- **Something does not work:** open an [issue](https://github.com/GabrielVergara/MasterSafeAuthenticator/issues/new/choose)
  with the bug form.
- **A security problem:** report it privately, never in an issue. See [SECURITY.md](SECURITY.md).

**Nobody can recover a forgotten master password**, including the author. Only a recovery key, a security key, Windows
Hello or a backup you made can get you back in. Please never post a vault, a backup, a password, a recovery key or a
code secret anywhere, and nobody from this project will ever ask you for one.

MasterSafe is a one-person project, so answers can take a few days.
