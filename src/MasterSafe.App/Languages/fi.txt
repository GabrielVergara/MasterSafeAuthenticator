A recovery key exists, so a forgotten master password does not lose the vault. => Palautusavain on olemassa, joten unohdettu pääsalasana ei hävitä holvia.
Set up a recovery key on the Recovery page. Without one, a forgotten master password cannot be undone. => Luo palautusavain Palautus-sivulla. Ilman sitä unohdettua pääsalasanaa ei voi korjata.
An encrypted recovery backup is written when the vault changes. => Salattu palautusvarmuuskopio kirjoitetaan, kun holvi muuttuu.
Turn on the automatic recovery backup on the Recovery page and choose a folder that is not on this disk (for example a USB drive). => Ota automaattinen palautusvarmuuskopio käyttöön Palautus-sivulla ja valitse kansio, joka ei ole tällä levyllä (esimerkiksi USB-tikku).
More than one way to unlock the vault is set up. => Holvin avaamiseen on useampi kuin yksi tapa.
Add a second way to unlock (for example Windows Hello or a security key) in Settings, in case one is not available. => Lisää Asetuksissa toinen avaustapa (esimerkiksi Windows Hello tai suojausavain) varalle.
Passwords can be checked against known breaches (only a short hash prefix is sent). => Salasanat voi tarkistaa tunnettuja vuotoja vastaan (vain lyhyt tiivisteen alku lähetetään).
Optional: allow the breach check in Settings to learn whether a password was leaked. It contacts an online service, so it is your choice. => Valinnainen: salli vuototarkistus Asetuksissa nähdäksesi, onko salasana vuotanut. Se ottaa yhteyden verkkopalveluun, joten päätös on sinun.
